# EQ 6.0 — эквалайзер, звук для игр и статус Bluetooth-устройств

Android-приложение (пакет `lv.budseq`, Android 9+). Пять вкладок: **Устройство**, **Эквалайзер**, **Игры**, **Музыка**, **Настройки**.

## Что умеет

**Устройство**
- Показывает всё, что подключено по Bluetooth: наушники, колонку, машину, часы, клавиатуру, геймпад и т.д.
- Сам определяет тип (по классу, названию и UUID) и рисует анимированную картинку. Если тип определился неверно — «Настройки устройства → Как выглядит».
- Заряд, если устройство его передаёт. Всплывающее окно при подключении (как у AirPods).
- Настройки для каждого устройства: громкость при подключении, какое приложение открыть, всплывающее окно, порог предупреждения о заряде.
- Galaxy Buds (протокол Samsung по RFCOMM, как в GalaxyBudsClient): заряд L/R/кейса, анимация кейса, шумоподавление, блокировка сенсора, встроенный эквалайзер наушников, поиск (писк). Крышка кейса рисуется открытой, только если хоть один наушник лежит в кейсе.
  Buds3 / Buds3 Pro / Buds4 рисуются «с ножками» и подсветкой Blade Light, в кейсе с прозрачной крышкой.
- **AirPods**: заряд L/R/кейса и зарядка из BLE-рекламы Apple (без подключения к ним), анимация кейса как у Buds:
  крышка открыта, только если хоть один наушник лежит в кейсе. Нужно разрешение «Устройства поблизости»
  (до Android 12 — «Геолокация», местоположение не используется).
- **Машина — фокус звука.** Крупный салон сверху, 6 точек: водитель, передний ряд, пассажир, сзади слева,
  весь салон, сзади справа. EQ знает, **где реально стоят динамики**: их можно расставить пальцем или выбрать
  схему (2 спереди, 4 в дверях, + твитеры, + сабвуфер, + центр). Фокус считается по физике: в выбранном месте
  ближний канал громче (1/r²), и EQ его приглушает, чтобы звук выстроился вокруг слушателя.
  «Проверить каналы» — три сигнала слева и три справа: EQ узнаёт, не перепутаны ли каналы и не моно ли магнитола.
  Режимы: мягко / обычно / сильно, руль слева или справа. Фокус включается сам, когда звук идёт в эту машину.
- **Этот телефон**: EQ узнаёт телефон (например, SM-S918B → Galaxy S23 Ultra), показывает Android,
  работает ли EQ на весь звук, есть ли Bluetooth LE, не усыпляет ли его экономия батареи, и даёт совет
  под прошивку (Samsung, Xiaomi, Huawei, OnePlus/OPPO). Профиль динамика называется по телефону.

**Эквалайзер**
- 9, 15 или 31 полоса; кривую можно «рисовать» пальцем. Визуализатор спектра за ползунками.
- Панч (компрессор на басу), усиление громкости с лимитером, баланс Л/П, выравнивание громкости, запас громкости.
- Работает на весь звук (DynamicsProcessing на сессию 0) и на сессии плееров.
- **AutoEQ**: коррекция под модель наушников из открытой базы [AutoEq](https://github.com/jaakkopasanen/AutoEq)
  (GraphicEQ или ParametricEQ пересчитываются в наши полосы). Коррекция хранится отдельно для каждых наушников
  и складывается с твоей кривой — на графике это оранжевая линия. При подключении наушников EQ сам ищет
  их модель и предлагает коррекцию (база ~1 МБ скачивается один раз по Wi-Fi).
- Свои настройки для каждого устройства.
- Пресеты: встроенные и свои; поделиться текстом, сохранить в JSON-файл, импорт из текста или файла.
- **Пресет по приложению**: Spotify, YouTube, игры — у каждого свой звук. Играющее приложение берётся из
  MediaSession, игры — по типу звука (USAGE_GAME). Когда приложение замолкает, возвращается прежний звук
  (если его не меняли руками).
- **Сравнение A/B**: большая кнопка — пока держишь, звучит оригинал без EQ на той же громкости
  (честное сравнение звука, а не громкости); лёгкая вибрация.
- **Пресет кодом и QR**: «Код и QR» — код вида `EQ-XXXX-XXXX-…` и QR-код (свой генератор, без библиотек);
  «Ввести код» — вставь код, ссылку или целое сообщение, посмотри кривую и нажми «Применить».
  Ссылки `eq://preset/<код>` и `https://gghub433.github.io/QE/p/<код>` открывают EQ.

**Игры**
- **Звук для игр** поверх твоей кривой (она не меняется): «Шаги врагов» — минус гул взрывов ниже 150 Гц,
  +5 дБ на 2–5 кГц, где шаги и перезарядка, тихие звуки громче; «Насыщенный» — плотный бас и яркий верх;
  «Голоса» — чат и диалоги. Ползунок «Насыщенность» — сила эффекта. Стрелялкам по умолчанию — шаги.
- **Телефон**: игры телефона, игровое время за неделю и сегодня; EQ сам узнаёт открытую игру и включает её звук
  (нужен «Доступ к истории использования»; без него — звук по умолчанию, когда игра зазвучит).
- **ПК · Steam**: библиотека Steam с обложками, часами в игре и за 2 недели (ключ Steam Web API + профиль,
  ключ хранится только на телефоне). Игры из Epic, GOG, EA, Ubisoft, Battle.net, Xbox, Riot — вручную,
  обложка ищется в магазине Steam.
- Нажми на обложку: откуда игра, звук для этой игры, **«Играть» / «Не играть»**. Игра с телефона
  открывается сразу с её звуком; игра с ПК — через Steam Link / Moonlight / Xbox на телефоне (звук идёт через EQ).
  «Звук для ПК» — тот же звук текстом для Equalizer APO, если играешь за самим ПК.
- **Запуск через EQ без задержки**: звук игры и режим низкой задержки включаются до старта игры
  (короткие кадры обработки, игровой режим Galaxy Buds); ярлык игры на главный экран и любимые игры
  в меню значка EQ. Закрыл игру — звук вернулся сам.

**Музыка**
- «Сейчас играет»: обложка, трек, исполнитель, перемотка, кнопки управления и живая **волна** в цвет обложки (нужен доступ к уведомлениям; кнопки работают и без него).
- Быстрые кнопки Spotify: «Любимые треки», «Поиск», «Открыть Spotify».
- EQ встроен в Spotify: Spotify → Настройки → Воспроизведение → Эквалайзер — откроется EQ и подключится прямо к звуку Spotify.
- **Music Time+**: сколько слушаешь музыку — неделя или месяц (график по дням), топ исполнителей и треков
  за период, итоги месяца (любимое устройство, пресет, исполнитель, ночное время) и достижения:
  10 / 100 / 500 часов, «Ночной слушатель» (больше 2 ч после 23:00), «Верен Buds» (90% времени на одних наушниках).
  Данные хранятся только на телефоне.
- **Итоги для сторис**: «Поделиться итогами» — картинка 1080×1920 (часы, любимое устройство, пресет,
  исполнитель, значки достижений, волна) уходит в Instagram, Telegram и т.д.
- **Таймер сна**: через 15–120 минут музыка плавно затихает за последнюю минуту и встаёт на паузу,
  громкость потом возвращается.

**Настройки**
- Язык: русский, English, latviešu, українська (или системный).
- **Оформление**: цвет акцента (8 цветов) и отдельно цвет волны — везде: кнопки, ползунки, графики, машина,
  виджет, всплывающее окно. «Цвет от обложки» — волна, чипы и свечение машины плавно перекрашиваются
  в цвет обложки трека. Фирменная волна с «вдохом» — на загрузке, в виджете и во всплывающем окне.
- **Сценарии** «когда → что»: машина подключилась → экран машины крупно и её пресет; наушники ночью
  (23:00–07:00, можно поменять) → на 3 дБ тише и мягче верх; наушники и приложение тренировки → больше панча.
- Автовключение (EQ только с Bluetooth-звуком), свои настройки для каждого устройства, **запуск вместе с телефоном** (и после обновления).
- Плитки в шторке: «EQ» (вкл/выкл) и «Пресет» (следующий пресет).
- **Виджет на главный экран** (4×2, растягивается): трек и обложка, фирменная волна, кнопки плеера,
  заряд наушников (L/R/кейс) и Music Time за сегодня.
- Всплывающее окно — разрешение «Поверх других приложений».
- **Автообновление** с GitHub Releases: проверка два раза в день, уведомление о новой версии, скачивание и установка в один тап.

## Сборка в Termux (прямо на телефоне)
```
termux-setup-storage
cd ~ && rm -rf BudsEQ && unzip -o ~/storage/downloads/BudsEQ-v5.0.zip
cd BudsEQ && bash termux-build.sh
```
Готовый `EQ.apk` окажется в папке «Загрузки». Он ставится поверх прошлой версии, настройки сохраняются.

Если Termux ругается на curl (`CANNOT LINK EXECUTABLE "curl"`), сначала выполни:
```
apt update && apt full-upgrade -y
```

## Сборка через GitHub (без компьютера)
Загрузи содержимое папки в репозиторий (вместе с `.github`), открой вкладку **Actions** —
через 3–5 минут в сборке появится **BudsEQ-apk** с `EQ-5.0.apk`.

## Автообновление

Приложение смотрит последний релиз в `gghub433/QE` (константа `Updater.REPO`).
**Репозиторий с релизами должен быть публичным** — у приватного GitHub не отдаёт релизы без входа.

Android ставит обновление, только если оно подписано **тем же ключом**, что и установленное приложение.
Поэтому выбери один способ и держись его.

**Способ 1: собираю в Termux** (ключ `~/.budseq-debug.keystore`)
1. Создай токен: github.com → Settings → Developer settings → Fine-grained tokens → доступ к репозиторию, *Contents: Read and write*.
2. Сохрани его в Termux: `echo ТОКЕН > ~/.eq-github-token`
3. Подними версию (см. ниже) и выполни `bash publish.sh` — соберёт APK и выложит релиз `vX.Y`.

**Способ 2: собирает GitHub Actions**
1. В репозитории: Settings → Secrets and variables → Actions → добавь секреты:
   - `KEYSTORE_BASE64` — ключ в base64 (в Termux: `base64 -w0 ~/.budseq-debug.keystore`);
   - `KEYSTORE_PASSWORD` = `android`, `KEY_ALIAS` = `debug`, `KEY_PASSWORD` = `android`.
2. Подними версию, закоммить и выполни `bash publish.sh --tag` (или поставь тег `v5.0` на GitHub).
   Actions соберёт подписанный APK и опубликует релиз. Без секретов APK собирается, но релиз не публикуется.

Описание релиза берётся из раздела «Что нового» ниже (`### X.Y`).

## Страница для QR-кодов (GitHub Pages)

QR-код пресета — это ссылка `https://gghub433.github.io/QE/p/EQ-…`. Камера телефона открывает её в браузере,
а страница `docs/404.html` показывает код и кнопку «Открыть в EQ». Чтобы страница работала:
Settings → Pages → Build and deployment → **Deploy from a branch** → ветка `main`, папка `/docs`.
Без Pages код всё равно можно ввести вручную: Эквалайзер → «Ввести код».

## После установки
- Разреши «Устройства поблизости» и уведомления.
- Вкладка «Музыка» → «Разрешить» — доступ к уведомлениям (трек, обложка, Music Time по исполнителям).
- «Настройки → Всплывающее окно» → «Поверх других приложений» (нужно и сценарию «Машина», чтобы открыть экран из фона).
- Вкладка «Игры» → «Разрешить» — доступ к истории использования (какая игра открыта, игровое время).
- Steam: ключ бесплатно на steamcommunity.com/dev/apikey (домен любой, например `localhost`);
  в приватности Steam открой «Сведения об играх». Ключ никому не отправляй — он хранится только в EQ на телефоне.
- На Xiaomi: в настройках приложения включи «Автозапуск», «Контроль активности» → «Нет ограничений».
- В Galaxy Wearable (или прямо в EQ) поставь встроенный эквалайзер наушников на «Обычный».

## Для разработки

Код — `app/src/main/java/lv/budseq/`:

| Файл | Что делает |
|---|---|

| `EqEngine` | DynamicsProcessing: EQ, панч, выравнивание, усиление, баланс, профили, пресеты |

| `EqWidget` | виджет: рисуется кодом в Bitmap, кнопки плеера |
| `CarFocusView`, `SpeakerTest` | салон машины, реальные динамики, фокус по физике, проверка каналов |
| `PhoneInfo` | этот телефон: модель, Android, возможности, советы под прошивку |
| `NowPlaying`, `MediaListener`, `WaveView` | «Сейчас играет» через MediaSession, волна |
| `ListenStats`, `MusicTimeView` | Music Time: статистика по дням, итоги, достижения, график |
| `AppPresets` | пресет по приложению (правила и слежение за плеером / игрой) |
| `Updater`, `UpdateReceiver` | автообновление с GitHub Releases |
| `BootReceiver` | запуск службы после перезагрузки и обновления |
| `EqTileService`, `PresetTileService` | плитки в шторке |
| `Lang`, `FlowLayout` | язык интерфейса, ряды кнопок с переносом |
| `Theme`, `CoverColor` | цвет акцента и волны, «живой» цвет обложки |
| `ShareCard`, `ShareProvider` | картинка итогов для сторис и отдача файла другим приложениям (замена FileProvider) |
| `PresetCode`, `QrCode` | пресет в короткий код (base32 + CRC-8) и свой QR-генератор (байты, коррекция M, версии 1–10) |
| `Games`, `Steam`, `CoverView` | звук под игру, игры телефона, игровое время, библиотека Steam, плитки обложек |
| `PlayActivity` | запуск игры через EQ без окна: звук и низкая задержка до старта игры, ярлыки |
| `Scenarios` | автосценарии: машина, ночь, тренировка |

Правила (иначе сломается сборка в Termux):
- Java 8 без лямбд и method references — только анонимные классы (старый `dx` не понимает invokedynamic).
- Без AndroidX и сторонних библиотек, интерфейс — кодом. Исключение — виджет: Android не умеет виджеты
  без XML, поэтому в `res/layout/widget.xml` только картинка и три кнопки, а всё содержимое рисует `EqWidget`.
- Все тексты — в `strings.xml` на 4 языках (`values`, `values-ru`, `values-lv`, `values-uk`), ключи совпадают.
- Без эмодзи в интерфейсе — только векторные иконки `res/drawable/ic_*.xml`.
- API новее 28 — только под проверкой `Build.VERSION.SDK_INT`.
- Новая версия: `versionCode`/`versionName` в `app/build.gradle` **и** `VERSION_CODE`/`VERSION_NAME` в `termux-build.sh`.

### 5.1
- AutoEQ: поиск модели наушников в базе AutoEq, коррекция складывается с кривой пользователя и хранится
  отдельно для каждых наушников; при подключении наушников EQ предлагает найденную модель.

### 5.0
- Вкладки: Устройство, Эквалайзер, Музыка, Настройки. «Назад» возвращает на первую вкладку.
- Машина: фокус звука — салон сверху, 6 мест, три режима силы, руль слева или справа.
- Музыка: живая волна в цвет обложки и Music Time — время прослушивания за день и неделю, топ исполнителей и приложений.
- Автообновление с GitHub Releases; публикация релиза из Termux (`publish.sh`) или через GitHub Actions по тегу.
- Запуск вместе с телефоном и после обновления.
