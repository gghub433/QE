# EQ 4.4 — эквалайзер и статус Bluetooth-устройств

## Что умеет

**Устройства**
- Показывает всё, что подключено по Bluetooth: наушники, колонку, машину, часы, клавиатуру, геймпад и т.д.
- Сам определяет тип и рисует анимированную картинку. Если тип определился неверно — «Настройки устройства → Как выглядит».
- Заряд, если устройство его передаёт. Всплывающее окно при подключении (как у AirPods).
- Настройки для каждого устройства: громкость при подключении, какое приложение открыть, всплывающее окно, порог предупреждения о заряде.
- Galaxy Buds2 (и Buds Live/Pro/новее): заряд L/R/кейса, анимация кейса, шумоподавление, блокировка сенсора, встроенный эквалайзер наушников, поиск (писк).

**Spotify и плееры**
- «Сейчас играет»: обложка, трек, исполнитель, перемотка, кнопки ◀◀ ▶ ▶▶ (нужен доступ к уведомлениям; кнопки работают и без него).
- Быстрые кнопки Spotify: «Любимые треки», «Поиск», «Открыть Spotify».
- EQ встроен в Spotify: Spotify → Настройки → Воспроизведение → Эквалайзер — откроется EQ и подключится прямо к звуку Spotify
  (работает даже там, где глобальный режим на телефоне недоступен).

**Звук**
- Эквалайзер на 9, 15 или 31 полосу; кривую можно «рисовать» пальцем.
- Визуализатор спектра за ползунками.
- Панч (бас-компрессор), усиление громкости с лимитером, баланс Л/П, выравнивание громкости.
- Моно — через системные настройки (Android не даёт включить его из приложения).

**Удобство**
- Плитки в шторке: «EQ» (вкл/выкл) и «Пресет» (следующий пресет).
- Автовключение: EQ работает только с Bluetooth-звуком.
- Свои настройки эквалайзера для каждого устройства.
- Пресеты: поделиться текстом, сохранить в файл, импорт из текста или файла.
- Языки: русский, English, latviešu, українська.

## Сборка в Termux (прямо на телефоне)
```
termux-setup-storage
cd ~ && rm -rf BudsEQ && unzip -o ~/storage/downloads/BudsEQ-v4.4.zip
cd BudsEQ && bash termux-build.sh
```
Готовый `EQ.apk` окажется в папке «Загрузки». Он ставится поверх прошлой версии, настройки сохраняются.

Если Termux ругается на curl (`CANNOT LINK EXECUTABLE "curl"`), сначала выполни:
```
apt update && apt full-upgrade -y
```

## Сборка через GitHub (без компьютера)
Загрузи содержимое папки в новый репозиторий (вместе с `.github`), открой вкладку **Actions** —
через 3–5 минут в сборке появится **BudsEQ-apk** с `app-debug.apk`.

## После установки
- Разреши «Устройства поблизости» и уведомления.
- «Включить всплывающее окно» → «Поверх других приложений».
- На Xiaomi: в настройках приложения включи «Автозапуск», «Контроль активности» → «Нет ограничений».
- В Galaxy Wearable (или прямо в EQ, если это Buds2) поставь встроенный эквалайзер наушников на «Обычный».
